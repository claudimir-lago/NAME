# NAME v1.0.0

**Nanoampere Meter for Electrophoresis**

This is the first public release of NAME, an open-source hardware module for measuring electrophoretic current in capillary electrophoresis systems.

## Highlights

- Working hardware already implemented in four CE instruments.
- Single-sided KiCad 10.0 PCB design with fabrication outputs and BOM.
- Differential ADS1220 measurement with hardware zero adjustment.
- Nominal current conversion of 200 nA/mV.
- Optional calibration factor for improved absolute accuracy.
- Arduino blocking and interrupt-driven acquisition examples.
- Bundled `ADS1220_WE_SoftSPI` library for flexible GPIO assignment.
- Documentation for pinout, integration, filtering, safety, and use with Zones.
- PDF schematic and photograph of the assembled board.
