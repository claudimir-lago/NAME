# Electrical safety

NAME is intended for use with capillary electrophoresis instrumentation, where potentially hazardous high voltages may be present elsewhere in the instrument.

The published design must not be interpreted as a complete safety architecture for a CE instrument. The user is responsible for evaluating grounding, insulation, enclosure, connectors, clearances, high-voltage isolation, and all interfaces to the host instrument before use.

Detailed safety notes specific to the NAME installation will be added to this document as the public documentation is completed.
