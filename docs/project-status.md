# Project status

NAME is not an early proof-of-concept. The hardware has been built, tested, and implemented in **four capillary electrophoresis (CE) instruments**.

The current public-release effort is focused on reproducibility and documentation rather than on demonstrating basic feasibility. In particular, the repository is being prepared to include:

- complete editable KiCad design files;
- fabrication outputs and bill of materials;
- minimal acquisition examples;
- calibration and characterization procedures;
- example electrophoretic-current data;
- guidance for use with Zones.

Some quantitative specifications are intentionally not stated yet. They will be added only after the corresponding measurements and validation procedures are documented.
