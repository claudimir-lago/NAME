# Contributing to NAME

Contributions are welcome, particularly reproducibility reports, hardware test results, corrections, firmware examples, and documentation improvements.

When reporting a hardware issue, please include the NAME project/release version, PCB revision when available, KiCad version if relevant, and enough information to reproduce the observation.

Please do not commit KiCad local-history, lock, autosave, or user-preference files. The repository `.gitignore` is configured to exclude these files.

Hardware contributions are expected to remain compatible with the repository's CERN-OHL-S-2.0 hardware licensing. Firmware and software contributions are expected to be compatible with GPL-3.0-or-later unless explicitly documented otherwise.
