# Hardware

This directory contains the KiCad source and fabrication outputs for NAME.

The current PCB is a **single-sided, through-hole design** with copper on the bottom layer only. The hardware has been built, tested, and implemented in four capillary electrophoresis instruments.

- `kicad/` — editable KiCad 10.0 project
- `gerbers/` — Gerber and drill outputs
- `fabrication/` — BOM and fabrication notes
